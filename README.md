# Autumn Branches Studio

Portfolio website in development.

## Structure

- `index.html` — studio homepage
- `projects/nura-wellness/` — Nura Wellness concept case study
- `projects/cafe-lumiere/` — Café Lumière concept case study
- `projects/verde-systems/` — Verde Systems concept case study
- `projects/mara-vale/` — Mara Vale concept case study

All four case studies are independent concept projects created to demonstrate strategy,
content-system thinking and creative direction. Placeholder visual areas are intentionally
left for original or properly licensed assets.
